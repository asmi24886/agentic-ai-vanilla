============================================================
KEY THING TO NOTICE
============================================================

There are three message roles:

"user"
    Original user input.

"assistant"
    An agent/LLM decision, usually a tool call.

"tool"
    The engine/tool's result, including HITL responses.

HITL does not create a special "human" message.

For a pending ask_user:
    USER -> becomes TOOL RESULT for ask_user

For a pending risky tool:
    USER -> becomes the decision that determines the TOOL RESULT

The entire messages array is retained and resent to the active
agent on every Claude call.
